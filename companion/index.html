Companion & Attacks

Feeds Power Attack's BAB-based scaling only — each attack below has its own Base To-Hit field. For sources with a known progression table, Hit Dice and BAB are pre-filled automatically; type over either to take manual control (use "Reapply progression" above to go back to auto-fill).
A species preset fills the Core Rulebook starting scores and attacks, including its 4th/7th-level advancement when reached. Everything remains manually editable afterward.

Evolutions

Check this only when making a single attack action this turn (not a full attack) — this is what makes Vital Strike (and its Improved/Greater versions) usable, on the one attack line you choose below in Results. It does NOT by itself change any attack's Strength multiplier or Power Attack scaling — those come from each attack line's own Mode (Primary/Secondary) and Dmg mult (×1.5 only when that line is truly the creature's only natural attack, or a two-handed weapon), set per line below in Attacks.

Ability Scores

Almost every companion uses Strength for both. Only change this for an unusual build (e.g. Dex-to-damage via a feat/feature that specifically grants it to natural attacks).

Attacks

Presets only fill editable attack rows; they never lock the creature to a species. Base To-Hit is the attack's BAB/size/other built-in value before its selected ability and active effects. Base Damage is a fixed amount before its selected ability and effects. Damage dice and damage type are also editable. For an Eidolon or Animal Companion/Mount at level 9+, the 3-or-more-natural-attacks Multiattack rule (see above) is applied automatically to every generated natural attack line — do not also add the "Multiattack" feat below and hand-adjust the same lines, or the -2 gets applied twice. Only a manually-added secondary natural attack line needs its own Base To-Hit adjusted by hand.

Modifiers — pick from the catalog per category, or add a custom one

Uses the shared Character Calculator catalog, filtered by the selected entity. Entries with an automatic adapter calculate immediately; the rest remain editable informational/custom effects. Poison, AC and saving-throw effects are shown only as notes when relevant.

Active Effects

Shared effects apply to every eligible attack. Attack-specific evolutions and manually targeted effects remain attached to their individual attack rows.

Results

Furious Focus (two-handed weapon only)
Furious Focus only waives Power Attack's penalty on the very first attack of the turn, made with the two-handed weapon — never a natural attack, and never if a different attack (natural or otherwise) came before it. This calculator doesn't track attack order, so confirm it here rather than have it assumed from display order.
Vital Strike (single attack action only)
Applies only to the one attack line selected here; every other line's Normal/Critical Damage above stays unaffected. A normal single attack action provides only one attack this round — see the Rend result below if Rend's condition is also checked.
