Character & Weapons

Caster Level is often lower than Character Level — a Paladin/Ranger's is Character Level − 3 (starting at 4th level), for example. Set it independently; it pre-fills spell entries below that scale with caster level (Divine Favor, Magic Weapon Greater, Wrath, Gorum's Armor...) instead of Character Level.
Character Level defaults this to full BAB (level, level-5, level-10...) — type over any box for a 3/4 or 1/2 BAB class, multiple iteratives, etc. The first box is also used as "BAB" everywhere else in the calculator (Power Attack scaling, etc.). Character Level also pre-fills other level-scaling fields (Sneak Attack dice, caster level, bard/paladin level...) when you add them from the catalog below.
Affects the handful of places that halve or ×1.5 a number (two-handed/off-hand Strength bonus, Power Attack/Deadly Aim two-handed damage). Off by default, matching the rules (round down); check it only if your table rounds up instead.
Drives Surge's die size and any other tier-scaling Mythic entries in the catalog below.

Attack bonus per line is BAB-derived automatically: Primary uses your full BAB; Secondary/Conditional use BAB−5 (or BAB−2 with Multiattack — e.g. a Rake, "Conditional", uses Secondary's math and is only usable when its own trigger is met).
