Magus Spell Library

Pathfinder 1e — full Magus spell list (its own distinct list, levels 0–6 only — Magi never get 7th-9th level spells, unlike a full 9th-level caster). A reference tool for browsing, searching, and shortlisting spells — not a session play-tool: no character level, no caster stats, no daily preparation tracking.
