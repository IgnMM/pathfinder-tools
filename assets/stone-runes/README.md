# Pathfinder illustrated arcane rune kit

This is the approved high-detail rune set based on the Spiritualist ghost and Witch cauldron examples.

Each class has three fully assembled transparent PNG assets:

- `class-assets/runes/alchemist-rune.png`
- `class-assets/seals/alchemist-seal.png`
- `class-assets/spines/alchemist-spine.png`

Match files strictly by their class-name prefix. Do not rebuild, redraw, recolor or add another rune over a seal or spine. `Other` uses an ornate question mark. The rune, seal and spine are already final assets.

Use `arcane-seals-background.png` behind Character Spell Sheets and `arcane-library-background.png` behind the bookshelf.
