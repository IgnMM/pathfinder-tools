Pathfinder 1e Inquisitor spell list (its own distinct list) — reusable for any inquisitor, save each one under their own name. Inquisitors are spontaneous casters like sorcerers: they know a fixed number of spells (the "Known" toggle), then cast any known spell of a level using that level's daily slot pool. Orisons (0-level) are known the same way but cast at will, unlimited. Uses Wisdom for bonus spells and DCs; caster level equals inquisitor level. Their single Domain grants powers, not bonus spells, so it isn't tracked here.
